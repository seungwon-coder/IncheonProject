# PV5 Vision V13.10 — 공개용 코드

PBV 생산 자동화 팀 프로젝트의 4개 Vision 검사와 PLC·로봇 공정 연동을 설명하는 공개용 선별본입니다. 내부 IP는 localhost 예시로 교체했으며 운영 PC의 실제 설정·로그·모델과 구분합니다.

## 역할과 기여
- Vision 담당 팀원: 학습 데이터 준비, 모델 학습, 객체 검출·검사 판정 알고리즘 개발.
- 포트폴리오 소유자: Dobot 제어를 주 담당으로 맡아 PLC를 통해 전달되는 Vision 결과와 로봇 동작 연결 조건을 검토. Vision 4 코드에 따른 Dobot_4 반환·창고 입고와 별도 출고 처리는 `../Dobot/`에 구현.
- 통합 지원: 팀장으로서 장치 간 인터페이스를 조율하고 연동 조건 검토·로봇 제어 로직 검증·통합 시운전을 지원.

Vision 소스 공개는 팀 전체 시스템 설명을 위한 것이며 모델·알고리즘 개발을 본인의 단독 성과로 주장하지 않습니다.

## 검사 역할
| Vision | 역할 |
|---|---|
| V1 | 주문 ROUND/EDGE와 램프 형상 비교 |
| V2 | 주문 COCOA/DARK와 시트 색상 비교 |
| V3 | 주문 램프·시트 색상·차종별 수량과 최종 조립 비교 |
| V4 | 단품 분류: 1 빈 지그, 2 ROUND, 3 EDGE, 4 COCOA, 5 DARK, 6 차체 |

## 구조
USB 카메라 4대 → `vision_core_server.py` → YOLO·판정·OPC-UA·HTTP 영상

Core가 카메라를 단독 소유하고 제어판·웹·SCADA는 영상/API 클라이언트로 연결됩니다. 제어판 종료와 Core 종료는 구분됩니다. `opc_control.py`는 OPC 연결, `engine.py`는 판정·검사 사이클, `camera_identity.py`는 장치 매핑, `ui_tasks.py`는 UI 요청 처리입니다.

## 실행
```powershell
cd Vision
python -m pip install -r requirements.txt
python control_panel.py
```
Windows에서는 `START_APP.vbs`로 제어판을 시작할 수도 있습니다. 설치 스크립트는 사용자 실행용이며 공개 준비 과정에서는 실행하지 않았습니다.

Core 시작 버튼으로 서버를 시작하고 `http://127.0.0.1:5000/`에서 4분할 영상, `/vision1`~`/vision4`에서 개별 영상을 확인합니다. 모델은 별도 준비가 필요합니다. 예시 `config.json`의 모델 경로는 `models/vision1_best.pt`~`vision4_best.pt`입니다. 카메라 번호·장치 경로·모델 클래스·태그를 현장에 맞춰 설정해야 합니다. 기본 PLC 실제 쓰기는 OFF이며 모델·태그·래더 검증 후 작업자 승인으로 전환합니다.

## 검증과 한계
`test_*.py`에는 판정·태그·OPC·UI·카메라 매핑 검사 코드가 있습니다. 일부는 장치 열거 또는 영상 라이브러리를 요구하므로 전체를 무조건 장비 없는 시험으로 취급하지 않습니다. 실제 카메라 4대, PLC 신호, 모델 정확도와 연속운전은 이번 공개 작업에서 검증하지 않았습니다. 과거 제목/health 문자열에 V13.7·V13.8이 남아 있을 수 있으며 소스 기준은 인수인계 V13.10입니다.

가중치는 [모델 안내](MODEL_INFO.md)를 참고하세요. 학습 그래프 수치와 설비 검증 결과는 구분합니다. 모델·데이터셋·GUI 사진은 이번 코드 게시에서 제외했습니다. 일괄 오픈소스 라이선스를 추가하지 않았습니다.
