# PV5 Vision V13.29 — 공개용 코드

PBV 생산 자동화 팀 프로젝트의 Vision 검사와 PLC·로봇 연동을 설명하는 공개용 선별본입니다. V13.10 공개본을 `pv5_control_hub_v13_29`의 코드로 갱신했습니다. 원본 현장 파일은 수정하지 않았습니다.

## 역할과 기여
- Vision 담당 팀원: 학습 데이터 준비, 모델 학습, 객체 검출·검사 판정 알고리즘 개발.
- 포트폴리오 소유자: Dobot 제어를 주 담당으로 맡아 PLC를 통해 전달되는 Vision 결과와 로봇 동작의 연결 조건을 검토. Vision 4 코드에 따른 Dobot_4 반환·창고 입고와 별도 출고 처리는 [Dobot 코드](../Dobot/)에 구현.
- 통합 지원: 팀장으로서 장치 간 인터페이스 조율, 공정 연동 조건·로봇 제어 로직 검증, 통합 시운전 지원.

Vision 알고리즘 개발과 로봇 연동·검증 지원은 구분하여 기록합니다.

## 검사 역할
| 구분 | 현재 판정 방식 |
|---|---|
| V1 | YOLO 램프 형상을 주문 ROUND/EDGE와 비교 |
| V2 | 검출한 시트 영역의 LAB 색상을 COCOA/DARK 기준색과 비교 |
| V3 | 시트1·시트2 ROI에서 갈색 계열 픽셀 비율로 제품 유무 판정. 주문별 시트 수량과 LED ON을 확인 |
| V4 | 단품 분류: 2 ROUND, 3 EDGE, 4 COCOA, 5 DARK, 6 차체. 빈 지그·미인식·색상 미분류·다중 부품은 0과 ERROR |

V3는 정확한 COCOA/DARK 종류나 램프 형상을 최종 판정에 사용하지 않습니다. LED 전용 ROI의 현재 밝기로 ON/OFF를 판단합니다. V13.29는 정규화 ROI 좌표를 실제 프레임 픽셀로 변환해 기준색 저장 오류를 수정합니다.

## 구조와 기능
카메라 4대 → Core 서버(카메라 단독 소유·YOLO/OpenCV 판정·OPC-UA·HTTP) → 제어판·웹·SCADA

시트1·시트2·LED 다각형 ROI 편집, 색상 기준 보정, 사용자 설정 영구 저장, OPC 자동 재연결을 지원합니다. 제어판 종료와 Core 종료는 별개입니다.

## PLC 신호 규칙
- V1~V3: 양품 FINISH, 불량 NG, 오류 ERROR 중 하나만 ON. 판정 직전 RUNNING OFF.
- V4: 정상 분류값 2~6과 FINISH, 비정상은 분류값 0과 ERROR.
- 결과 비트는 기본 1초 출력 후 OFF. PLC는 결과를 놓치지 않도록 저장해야 합니다.
- V4 CLASS_RESULT 초기화는 PLC 담당이며 Python은 JIG_Dispose를 읽거나 기다리지 않습니다.
- START OFF 확인 후 다음 ON에서 검사. 설정상 검사 제한시간 3초, 안정 판정 5프레임, V3 LED 점등 대기 0초.

## 공개용 설정과 실행
내부 IP는 localhost로, 카메라 장치 경로는 빈 값으로 바꿨습니다. 현장 ROI와 기준색은 제거했습니다. 실제 검사 전에 카메라·태그·모델·시트1/2 및 LED ROI·기준색을 설정해야 합니다. V3 객체 ROI는 빈 값이므로 그대로 정상 검사 가능한 현장 설정이 아닙니다.

```powershell
cd Vision
python -m pip install -r requirements.txt
python control_panel.py
```
Windows에서는 START_APP.vbs로 제어판을 시작할 수도 있습니다. Core 시작 후 `http://127.0.0.1:5000/`에서 4분할 영상을 확인합니다. 실제 PLC 쓰기는 기본 OFF이며 현장 검증과 작업자 승인 후 전환합니다.

기준색·ROI는 `%LOCALAPPDATA%/PV5_VISION_CONTROL/user_settings.json`에 저장되어 버전 폴더가 바뀌어도 복원될 수 있습니다. 기존 현장 설정은 별도 백업·검토하세요.
