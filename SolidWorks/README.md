# SolidWorks 전체 설비 모델링

[Source/테이블_최종](Source/테이블_최종/)에 전체 설비 조립 모델과 부품 275개를 보관합니다.
최상위 조립 파일은 공정구상도_수정중.SLDASM입니다. OldVer 및 SolidWorks 잠금 임시 파일은 제외했습니다.

## 담당 범위
본인이 전체 설비 조립 모델을 구성하고 장치를 배치했습니다. 개별 부품에는 제조사 제공 및 참조 모델이 포함될 수 있으며, 모든 부품을 직접 제작했다는 의미는 아닙니다. 일괄 오픈소스 라이선스를 추가하지 않았습니다.

## 내려받기
Git LFS 설치 후 저장소를 복제하고 git lfs pull을 실행하세요. 폴더 전체를 유지해 최상위 조립 파일을 여세요.

## 확인 범위
원본 275개의 SHA256을 검증했습니다. SolidWorks에서 외부 참조·누락 부품·간섭·정상 재생성을 검증하지 않았습니다. 원본 CAD를 재저장하지 않아 파일 내 작성 정보나 참조 경로가 남아 있을 수 있습니다. PDF의 교육용 표시는 원본 그대로 유지했습니다.
