# PBV 생산 자동화 — Dobot·Vision 포트폴리오

PBV 생산 자동화 팀 프로젝트에서 담당한 Dobot Magician 4대 제어 코드와 관련 문서입니다.

## 주요 구현
- 로봇별 독립 Worker 프로세스 및 오류 격리
- PLC·KEPServerEX OPC-UA START/READY/RUNNING/FINISH/ERROR 연동
- 수동·자동 운전 GUI, 좌표 티칭, 경로 확인
- 비전 분류 결과에 따른 반환과 차량 하부 창고 입출고
- SCADA 좌표 32개 전송 및 오래된 좌표 제외

## 공개 범위
소스 기준: 로컬 Dobot main의 ce25ddf (2026-10-02). 공개본은 별도 새 이력으로 게시하여 비공개 저장소의 과거 이력을 포함하지 않습니다.

실제 로봇 시리얼번호, 현장 티칭 좌표, 내부 서버 IP와 재고 상태는 예시값으로 바꿨습니다. PLC·SCADA·CAD 등 팀 전체 자료, 내부 점검 메모, 생성된 설비 문서와 제조사 SDK 바이너리/래퍼는 포함하지 않습니다. 제조사 SDK는 공식 배포처에서 별도로 준비하세요. 원본 개발 문서의 SDK 포함 안내는 원본 작업 환경에 대한 설명입니다.

자동시험과 실제 설비 시운전 결과는 구분합니다. 원본 환경의 전체 자동시험은 asyncua 미설치 때문에 1개 모듈을 로딩하지 못했습니다. 공개본의 샘플 설정은 실제 장비 운전 설정이 아니며 현장 연결·티칭이 필요합니다.

일괄 오픈소스 라이선스는 부여하지 않았습니다. 코드 공개와 제3자 자료의 재배포 권한은 별개입니다.

## Vision 코드와 역할 구분
[Vision V13.29 공개용 코드·문서](Vision/README.md)를 추가했습니다. Vision 알고리즘 개발은 팀원이 담당했으며, 포트폴리오 소유자는 Dobot 제어·Vision 결과의 로봇 공정 연동과 검증·통합 지원을 담당했습니다. 모델 바이너리·전체 데이터셋·현장 운영 설정은 포함하지 않습니다. 사용 모델은 [모델 안내](Vision/MODEL_INFO.md)에 기록합니다.

### Vision V13.29 갱신
V3는 시트별 ROI에서 갈색 계열 픽셀 비율로 제품 유무를 확인하고 주문별 수량과 LED ON을 검사합니다. V1~V3 결과는 FINISH/NG/ERROR 중 하나를 1초 출력하며 V4 CLASS_RESULT 초기화는 PLC가 담당합니다. 실제 장치 경로·ROI·색상 기준은 공개용 설정에서 제거했습니다. 모델 4개와 기존 best.pt의 해시 동일성을 확인했으며 바이너리는 제외했습니다. 선택한 모의 시험 5개가 통과했고 실제 설비 운전은 이번 갱신에서 검증하지 않았습니다.
